# Space Shooter (Web Edition)

A fast-paced retro space shooter game built with Python and Pygame-CE. Destroy meteors and survive as long as possible.

Playable locally and in modern web browsers via WebAssembly ([Pygbag](https://pygame-web.github.io/)).

## How to Run Locally

### Prerequisites
- Python 3.10+
- `pip install pygame-ce pygbag`

### Play Locally
```bash
python main.py
```

### Run in Browser Locally
```bash
python -m pygbag main.py
```
Open `http://localhost:8000` in your web browser.

## Controls
- **Arrow Keys** or **WASD**: Move ship
- **Space**: Fire laser / restart after game over
- **Escape**: Quit game
